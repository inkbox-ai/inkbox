# Cursor plugin changelog

## 1.0.0 - 2026-08-25

- Add the native Cursor Plugin manifest.
- Connect Cursor to the hosted Inkbox MCP server through browser OAuth.
- Add skills for email, SMS/MMS, iMessage, calls, contacts, notes, identity
  settings, and agent-to-agent tasks.
- Publish those workflows from the shared root `skills/` catalog used by the
  other official agent plugins.
- Use the complete square Inkbox octopus logo from the Inkbox website assets.
